Платформа, где можно **заказать автозапчасти оптом из Дубая** (когда нужно быстро/выгодно и без “квеста” по поставщикам) **или купить у частных продавцов и других поставщиков прямо на площадке**.

Изначально это была потенциальная бизнес-идея, а сейчас проект находится в стадии **MVP** и активно допиливается. Делали вдвоём: один **бэкендер**, один **фронтендер**.  

---

## 🧠 Зачем это всё

После ухода многих автобрендов из РФ стало банально сложнее и дороже доставать оригинальные детали и нормальные аналоги. При этом в Дубае часто:
- больше выбор,
- проще найти нужное,
- цены могут быть приятнее.

Мы хотим сделать сервис “в одно окно”: **нашёл → заказал → привезли**, плюс дать возможность **другим поставщикам и частникам** продавать свои детали внутри платформы.

---

## ✨ Что в MVP (и куда идём)

**MVP-идея:**
- каталог / карточки запчастей
- оформление заказа (опт из Dubai + marketplace-лоты)
- базовая витрина продавцов (поставщики / частники)

**Дальше (roadmap, high-level):**
- личный кабинет продавца + управление ассортиментом
- модерация, статусы, уведомления
- логистика/расчёт доставки и интеграции с поставщиками
- рейтинги, отзывы, “безопасная сделка” (если понадобится)

---

## 🗂️ Структура репозитория (monorepo)

- `backend/` — серверная часть (API)
- `frontend/` — веб-клиент
- `mobile/` — мобильный клиент
- `nginx/` — прокси/роутинг для окружений
- `docker-compose.yml` — локальный запуск всего добра

---

## ⚙️ Технологии

По-крупному:
- **Backend:** Python (API)
- **Frontend:** TypeScript (Web)
- **Mobile:** Kotlin (Android)
- **Infra/Dev:** Docker Compose, Nginx

🔍 Key engineering decisions (коротко)

Monorepo, чтобы фронт/бэк/мобилка не жили “в разных вселенных”

Docker Compose для быстрого старта на любой машине

Nginx как точка входа/прокси (удобно для окружений и роутинга)
