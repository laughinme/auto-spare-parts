# Auto Spare Parts — маркетплейс автозапчастей (MVP)

Платформа, где можно **заказать автозапчасти оптом из Дубая** (под поставку) или **купить у частных продавцов / локальных поставщиков** прямо на площадке.

Идея родилась очень приземлённо: из РФ ушло много брендов, цены и доступность скачут, а в Дубае часто можно купить **выгоднее и проще** — если сделать нормальный сервис, который берёт на себя поиск, оформление и дальше “доводит” заказ до пользователя. Параллельно мы открываем витрину для других поставщиков и частников: хотите продавать свои детали — пожалуйста, размещайтесь.

Проект сейчас в стадии **MVP** и будет активно дорабатываться.

---

## Кто делал

Делали вдвоём: **один бэкендер + один фронтендер**. Изначально как потенциальная бизнес-идея, сейчас — честный MVP в разработке.

---

## Что уже есть (и что задумывалось в MVP)

- Каталог/лента запчастей и карточки
- Два сценария покупки:
  - **оптовая поставка из Дубая** (заказ/заявка)
  - **покупка у продавцов на платформе**
- Роли (покупатель/продавец) и базовые сущности под маркетплейс
- База под дальнейшее: логистика, статусы, платежи, кабинеты, модерация


---

## Архитектура

Репозиторий монорепой: всё в одном месте — так проще развивать MVP.

- `backend/` — API и бизнес-логика
- `frontend/` — веб-клиент
- `mobile/` — мобильное приложение
- `nginx/` — прокси/роутинг
- `docker-compose.yml` — локальный запуск всего зоопарка

---

## Технологии

**Backend**
- Python (API)
- Postgres (основная БД)
- Redis (кэш/очереди/фоновые штуки по мере роста)
- Миграции (Alembic) + локальный запуск через ASGI (Uvicorn)

**Frontend**
- TypeScript + React-экосистема (веб-клиент)
- Деплой на Vercel (для быстрого MVP)

**Mobile**
- Kotlin (Android)

**Infra**
- Docker / docker-compose
- Nginx
